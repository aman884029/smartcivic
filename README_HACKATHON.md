# SmartCivic 3.0 — Hackathon Build

## Run
```bash
npm install
npm start
```
Then open: `http://localhost:3000`

## HD cinematic background
This build includes a **local 1920x1080 MP4** background (`public/smartcivic-hd-bg.mp4`) so the cinematic background works without depending on an external video website. It also includes the matching high-resolution PNG fallback (`public/smartcivic-hd-bg.png`).

The scene visually represents civic problems such as traffic congestion, rain/flooding, potholes, roadside waste, pedestrians, utility wiring and public transport, matching the SmartCivic project theme.
